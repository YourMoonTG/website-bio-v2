# 🚀 Быстрый старт: Локальный редактор статей

## Что это?

Локальный редактор статей позволяет писать статьи локально, а они автоматически загружаются в GitHub и публикуются на прод.

## ⚡ Быстрая настройка (5 минут)

### 1. Создайте GitHub Personal Access Token

1. Перейдите: https://github.com/settings/tokens
2. Нажмите "Generate new token (classic)"
3. Установите права:
   - ✅ `repo` (полный доступ)
   - ✅ `workflow` (для GitHub Actions)
4. Скопируйте токен

### 2. Откройте редактор

1. Откройте файл `admin.html` в браузере (локально, из папки `source/`)
2. Введите токен в поле "GitHub Personal Access Token"
3. Нажмите "Сохранить"

### 3. Начните писать!

1. Нажмите "+ Новая" для создания статьи
2. Заполните метаданные и напишите статью
3. Нажмите "💾 Сохранить в GitHub"
4. Готово! Статья автоматически появится на проде через несколько минут

## 🔄 Как это работает?

```
Локально (admin.html)
    ↓ Сохранение
GitHub (blog/content/*.md)
    ↓ GitHub Actions
GitHub (blog/posts/*.html)
    ↓ GitHub Pages
Прод (yourmoontg.github.io)
```

## ✅ Проверка

После сохранения статьи:

1. Проверьте GitHub репозиторий → вкладка "Actions"
2. Убедитесь, что workflow "Build Articles" запустился
3. Подождите 2-3 минуты
4. Проверьте сайт: https://yourmoontg.github.io/blog.html

## ⚠️ Важно

- Редактор работает **только локально** - не открывайте `admin.html` на проде
- Токен хранится в localStorage браузера - не коммитьте его в репозиторий
- Все изменения идут через GitHub - локальные изменения не влияют на прод напрямую
